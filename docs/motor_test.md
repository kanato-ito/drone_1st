# モーター単体試験（motor_test）

プロペラを外した状態で、モーターを1個ずつ低いデューティで回し、配線・回転方向・電流・発熱を確かめる試験アプリ。
制御ループ・IMU・状態機械は使わない（`motor_pwm` と電池電圧の読み取りだけ）。

## 1. 作ったもの

| ファイル | 役割 |
| --- | --- |
| `firmware/apps/motor_test.c` | 試験アプリ。USBシリアルの1文字コマンドでモーターを選び、なだらかに回す |
| `firmware/CMakeLists.txt` | `motor_test` ターゲットとデューティ上限 `FC_MOTOR_TEST_DUTY_MAX` |

`src/` と他のアプリは変えていない。SDK に触るのはアプリ側だけ（試験アプリなので純粋C11の規則は対象外）。

## 2. 基板の前提

| モーター | GPIO | 位置 | 設計上の回転方向（基板を上から見て） |
| --- | --- | --- | --- |
| M1 | GP0 | 右後ろ | 時計回り |
| M2 | GP15 | 右前 | 反時計回り |
| M3 | GP18 | 左後ろ | 反時計回り |
| M4 | GP17 | 左前 | 時計回り |

- ローサイドNch MOSFET（AO3400A）。ゲートは Picoピン → 100Ω → ゲート、ゲート → 10kΩ → GND。デューティ0 = Low = オフ
- 電池電圧は GP28（ADC2）、分圧比 2.0（R9・R10 とも 100kΩ。発注版基板で確認済み）
- **GP0 は SDK 既定のUART送信ピン。** `pico_enable_stdio_uart(motor_test 0)` でUARTを無効にしてある。ターミナルはUSBシリアルだけ使う

## 3. 安全の仕組み

- 同時に回るのは常に1個だけ。`motor_pwm_set` に渡す配列は、選んだモーター以外を必ず0にする
- デューティ上限 `MOTOR_TEST_DUTY_MAX`（既定 0.30）。`+` でこれを超えない
- 実際に出すデューティは目標へ 10ms ごとに 0.005（毎秒 0.5）ずつ近づける（上げも下げも同じ速さ）
- 次の3つは**なだらかにせず即座に全部0**: 停止コマンド、自動停止（最後のキー入力から 10秒）、USBの切断
- ウォッチドッグ 200ms。固まったら再起動し、`motor_pwm_init` で0に戻る。起動時に前回がWDT再起動だったら表示する
- 端末が出力を読まないときに `printf` が待つ上限を 20ms にしてある（SDK既定の 500ms だとウォッチドッグより長く、表示の詰まりで再起動する）
- `g` は目標0でも受け付けるが何も回らない（`+` で上げて初めて回る）。モーター未選択の `g` は何もしない

## 4. ビルドと書き込み

```sh
cd firmware
cmake -B build -G Ninja -DPICO_SDK_PATH=<pico-sdk のパス>
ninja -C build motor_test        # build/motor_test.uf2 ができる
```

書き込みは `docs/step2_imu_fifo.md` と同じ（BOOTSELを押しながらUSBをつないで uf2 をコピー）。IMUは使わないので、つないでいなくてよい。

デューティ上限を変えるとき（CMake の段階で `0 < x <= 1.0` を検査する。範囲外は `FATAL_ERROR`、0.30 より大きいと警告）:

```sh
cmake -B build -DFC_MOTOR_TEST_DUTY_MAX=0.20 ...
```

## 5. 手順

> **警告: 必ずプロペラを外す。** 回転数が上がると手や基板に当たって危ない。

1. **プロペラを外す。** モーターは基板か試験台に固定し、軸や線に触れないようにする
2. **電源**: 安定化電源を **4.0V、電流上限 1.5A**、OCPは切る（CCで使う）。デューティ0.30で1個あたり約1A流れる見込み（HW設計書の実測：推力 ≒ 9.4 × デューティ × 電圧 [g]、電流 ≒ 0.089 A/g から、0.30 × 4.0V で約11g・約1.0A）。電池は使わない
3. 電源をつなぎ、Pico を USB でPCにつなぐ。ターミナル（DTRを出すもの。VS Code のシリアルモニタなど）を開く
4. 題名・注意・ヘルプが出て、電池電圧が約 4.0V と出ることを確かめる（`b` でも表示できる）。電源をつないでいないと「2V未満」と出る
5. **1個ずつ**:
   1. `1`〜`4` でモーターを選ぶ（選び直すたびに全部止まり、目標が0に戻る）
   2. `g` で開始 → `+` を押して 0.05 ずつ上げる。0.05 → 0.10 → … と、電流・音・回り方を見ながら進める。上限は 0.30
   3. 回転方向と電流を確かめる（6章）
   4. スペース（`0` `s` でも可）で止める。電流が回す前の値に戻ることを確かめる
   5. 止めてから、モーターとFETの発熱を指で確かめる（7章）
6. M1 → M2 → M3 → M4 の順に繰り返す
7. 回している間は1秒に1行出る: `M1 右後ろ 時計回り 目標=0.100 実=0.100 Vbat=3.98V 残り9.0s`。残りは最後のキー入力からの自動停止までの時間（キーを押すたびに10秒に戻る）

## 6. 回転方向の確かめ方

- 基板を**上から見て**、設計の向きに回っていればよい（M1・M4 = 時計回り、M2・M3 = 反時計回り）
- 軸が見えにくいときは、軸に小さな目印（マスキングテープの切れ端など）を付けると分かりやすい。低いデューティ（0.05〜0.10）で確かめる
- 逆に回ったら、電源を切り、そのモーターの2本のリード線を入れ替えて**設計どおりの向き**にする。ミキサーの符号表とプロペラの向き（CW/CCW品）は設計どおりの回転を前提にしているので、変えない
- 選んだ番号と違うモーターが回ったら配線違い。ピン割り当て（2章）と基板の配線を照らして直す

## 7. 電流・発熱の確かめ方

- 電源の電流表示で、停止中（回す前）の電流を控えておく。回している間は、デューティに応じて電流が増える
- **止めたときに電流が回す前の値へ戻る**ことを確かめる。戻らなければゲート側の問題（FETのオンのまま、ゲートのプルダウン不良など）
- 電流制限に当たって電圧が下がる（`Vbat` が大きく落ちる）ようなら、そこで止める
- 発熱: 各デューティで30秒ほど回したあと、止めてモーター・AO3400A・配線を指で触る。熱くて触れない、焦げた臭いがする場合は異常
- 電池電圧の目安を表で控える（デューティ・電流・Vbat・熱の感触）

## 8. 合格条件

| # | 条件 |
| --- | --- |
| 1 | `1`〜`4` のそれぞれで、選んだモーターだけが回り、他の3個は回らない |
| 2 | 回転方向が設計どおり（M1・M4 = 時計回り、M2・M3 = 反時計回り） |
| 3 | 4個とも、デューティ 0.30 までなめらかに回る（途中で止まる、異音がする、がない） |
| 4 | 回している間の電流が電流制限に届かず、電圧降下が小さい |
| 5 | スペースで即座に止まり、電流が回す前の値に戻る |
| 6 | 回したまま10秒キーを押さないと止まり、「自動停止」と表示される |
| 7 | 回している最中に USB ケーブルを抜くと止まる（電源は入れたまま。電流で確かめる） |
| 8 | モーター・FETが触れないほど熱くならない |

## 9. 異常時の対処

| 症状 | 対処 |
| --- | --- |
| 何も表示されない | USBシリアルのポートを確認。UARTは無効（GP0にUSB-シリアル変換をつないでも出ない）。BOOTSELで書き込み直す |
| 回すはずのないモーターが回る | すぐスペースで停止し、配線（ゲートのGPIO）とピン割り当てを確認。止まらなければ電源を切る |
| 逆に回る | 6章。電源を切り、リード線を入れ替えて設計どおりの向きにする |
| 回らない（電流も増えない） | ゲートの配線、100Ω・10kΩ、FETの向き。電流が増えるのに回らないなら、モーターの断線・固着 |
| 止めても電流が戻らない | FETが短絡・ゲートが浮いている可能性。電源を切り、基板を確認 |
| 電圧が大きく落ちる | 電流制限に当たっている。デューティを下げ、電流制限と配線の太さ・接触を確認 |
| 触れないほど熱い | すぐ停止して電源を切る。冷めるまで再開しない。原因（短絡、固着、デューティの過大）を調べる |
| 突然再起動した | 起動時に「ウォッチドッグで再起動した」と出る。モーターは0に戻っている。再現するなら報告（printf の詰まりなど） |
| 「電池電圧 2V未満」 | 電源の接続、ADC（GP28）の分圧回路を確認 |

## 10. 提案・迷った点（メモにない決め）

1. 選び直し（`1`〜`4`）は、回している最中でも一度全部止めてから切り替える。選んだ番号は停止後も残す
2. 自動停止のタイマーは、回している間のどのキー入力でも延びる（`+`/`-`/`b`/`h` を含む）
